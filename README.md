# Multi-LLM Connector (GPT + Claude + Gemini in one dialog)

Локальный интерфейс, который позволяет добавить несколько AI-провайдеров и вести:

- обычный режим: один запрос сразу в несколько моделей;
- relay-режим: модели отвечают **друг другу** по очереди в одном окне (например, GPT -> Claude -> Gemini -> следующий раунд).

## Возможности

- Подключение OpenAI-compatible моделей (GPT и совместимые шлюзы)
- Подключение Anthropic Claude
- Подключение Google Gemini
- Параллельный fan-out (один запрос всем)
- Relay-диалог между моделями по раундам
- Простая веб-панель для управления провайдерами

## Быстрый старт

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m app.main
```

Откройте `http://localhost:8000`.

## Как использовать

1. Добавьте провайдеров (GPT / Claude / Gemini) через форму.
2. Выберите провайдеры чекбоксами.
3. Выберите режим:
   - **Один запрос всем** — все отвечают независимо.
   - **AI отвечают друг другу по очереди** — каждый следующий AI видит уже написанное предыдущими.
4. Введите сообщение/тему.
5. Для relay-режима задайте число раундов и запустите.

## API

- `GET /api/providers`
- `POST /api/providers`
- `DELETE /api/providers/{id}`
- `POST /api/chat` — fan-out запрос
- `POST /api/chat/relay` — поочередный диалог AI между собой

## Примечания

- Ключи хранятся только в памяти процесса (без записи на диск).
- Для по-токенного realtime-стриминга можно расширить relay до SSE/WebSocket.
