# Текст ↔ Голос (без бэкенда)

Простое веб-приложение, которое работает прямо в браузере:
- **Текст → Голос** через Web Speech API (`speechSynthesis`)
- **Голос → Текст** через Web Speech API (`SpeechRecognition` / `webkitSpeechRecognition`)

## Запуск
Ничего устанавливать не нужно.

### Вариант 1
Просто откройте `index.html` в браузере.

### Вариант 2 (локальный сервер)
```bash
python -m http.server 5000
```
Затем откройте: `http://localhost:5000`.

## Важно
- Для распознавания речи нужен доступ к микрофону.
- Поддержка `SpeechRecognition` зависит от браузера (лучше всего Chromium-браузеры).
- В некоторых браузерах локальный файл `file://` может ограничивать часть API — тогда используйте запуск через `http.server`.
